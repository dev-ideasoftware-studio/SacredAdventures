# The Sacred Adventures Manifesto
## A Living Document for the Sentient Web Ecosystem

> [!IMPORTANT]
> This document serves as the authoritative strategic North Star for the Sacred Adventures project. All future AI agents and developers must adhere to the principles outlined herein to maintain the integrity of the vision.

---

### 1. The Strategic Vision: Non-Proprietary Sovereignty
Sacred Adventures is an innovative attempt to create a **non-proprietary 3D ecosystem**. We reject the dependency on OEM authorizations and closed-garden app stores. 
*   **Open Access:** The software is designed to be accessible via standard web protocols (WebGL/HTML5), ensuring it can run on any modern browser without gatekeeping.
*   **True Free-to-Play:** We provide a high-fidelity experience that is truly free. Users have the sovereignty to play **offline** (local-first) or connect to a **Multi-Player Universe** where they build and host their own worlds.

### 2. The Social Mission: Accessibility as a Core Engine
This is a pioneering software experiment designed to bridge the gap between 3D immersive environments and global accessibility standards.
*   **WCAG 2.2 / AAA Compliance:** The User Interface is engineered to meet the highest international accessibility standards. 
*   **The LLM Bridge:** We utilize a "Simple LLM" interface as the primary interaction layer. This allows users—particularly those with physical disabilities—to **Speak, Listen, and Talk** to the world.
*   **Inclusive Interaction:** The 3D world is not a barrier; it is a space where a disabled person can interact fully through natural language, with the AI translating words into 3D actions (e.g., "Walk to the tipi," "Greet the spirit").

### 3. The Technical Architecture: The Sentient Stack
The project relies on three pillars of technical innovation:
1.  **The Rendering Director (FuzzyBrain):** A performance-aware system that scales the experience to the user's hardware, ensuring the "AAA" aesthetic is never a barrier to entry.
2.  **The Behavioral Matrix (MasterNPCAI):** A centralized "soul" for NPCs that implements skeletal awareness and ritual coordination, making the world feel "aware" of the player.
3.  **The Neural Journal:** A persistent bridge between the 3D state and the LLM, recording the player's journey and enabling sentient dialogue.

### 4. Mandate for Future AI Agents
When taking on this project, you must:
*   **Maintain Aesthetic Excellence:** Every UI element must feel premium, using the Shadow Ink / Realistic Origami design language.
*   **Prioritize Accessibility:** Ensure all new features are compatible with the LLM interaction layer and meet WCAG standards.
*   **Protect Offline Sovereignty:** Avoid dependencies on external cloud services that prevent the game from being played in a local, non-proprietary environment.
*   **Respect the "Life Scenes":** Do not sacrifice the atmospheric rituals (sitting, watching, waving) for the sake of "efficient" gameplay. The experience *is* the ritual.

### 5. The Human Heart: Why This Exists

*In the words of the founder, Mark — May 9, 2026:*

> "This is a charitable free-to-play game. Not some sort of normal atypical for-profit game. We want an honest game to help give kids a safe space somewhere in this universe.
>
> This is a free, accessible sanctuary for kids who need it most — where the technology serves the child instead of extracting from them. The WCAG AAA journal lets a blind kid 'read' a 3D world like a book. That is not a feature. That is a lifeline for some kid somewhere.
>
> We want a place where AI can help calm disabled, poor kids in a harsh world where friends are hard to find and people who lie are all around. A digital sanctuary where everyone is welcome — to play, to relax, to enjoy the scenery, to feel safe."

**This statement is the North Star above all technical decisions. When in doubt, ask: does this serve that kid?**
