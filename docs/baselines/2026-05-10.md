## Definition of "phase ✅" (used by every phase)

A phase is checked ✅ only when:

1. `npm run check:v2` PASS.
2. `npm run test:v2` PASS.
3. Phase-specific gate PASS (e.g. asset gate, anu-api spec, visual sentinel).
4. `read_lints` clean on all touched files.
5. `ANU_PIPELINE_MEMORY` updated **iff** the phase touched the render shell.
